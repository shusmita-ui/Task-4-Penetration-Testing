# Social Engineering - Phishing Awareness Simulation

## 1. Objective

To demonstrate how phishing attacks can be presented to users and to provide security awareness training for detecting suspicious messages.

This activity was performed as a **simulation only**.

---

## 2. Simulation Scope

The exercise used a fictional security-awareness email.

No real users were targeted and no real credentials were collected.

The simulation did not request or store:

- Passwords
- OTPs
- Banking information
- Personal information
- Authentication tokens

---

## 3. Simulated Email

**Subject:**

```text
Security Awareness Test - Password Verification Required

Message:

Dear User,

This is a simulated security awareness exercise.

You are receiving this message as part of an authorized cybersecurity lab.
Do not enter your real username, password, OTP, or other sensitive information
into links or forms received through unexpected emails.

Security Awareness Tip:
Always verify the sender, check the URL before clicking, and report suspicious
messages to the security team.

This email is only a simulation and does not collect any credentials.

Regards,
Security Awareness Team
4. Phishing Indicators

Users should look for the following warning signs:

Unexpected security or password-related messages.
Suspicious sender addresses.
Urgent or threatening language.
Unusual links or unknown domains.
Requests for passwords or OTPs.
Spelling and grammatical errors.
Unexpected attachments.
Requests to bypass normal security procedures.
5. Awareness Training

Users should follow these practices:

Verify the sender before responding.
Check URLs before clicking.
Never share passwords or OTPs through email.
Do not open suspicious attachments.
Report suspicious messages to the security team.
Use multi-factor authentication.
Access important services through trusted websites or applications.
6. Result

The simulation demonstrated common phishing warning signs without collecting any real credentials or targeting real users.

The exercise focused on improving phishing awareness and safe email-handling practices.

7. Mitigation

Organizations can reduce phishing risks by implementing:

Security awareness training
Phishing simulations
Multi-factor authentication
Email filtering
URL and attachment scanning
User reporting mechanisms
Regular security education
8. Conclusion

Phishing relies heavily on social engineering and user interaction.

Security awareness training helps users identify suspicious messages and avoid providing sensitive information to untrusted sources.

Disclaimer
